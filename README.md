# Gerardo Pressure Washing — Website

Bilingual (EN/ES) marketing site for Gerardo's pressure-washing business in Jacksonville, FL. Includes a print-ready business card.

## Pages

| Path | Purpose |
|---|---|
| `index.html` | Hero, services overview, coverage map, testimonials, CTA |
| `services.html` | 8 service detail rows + 4-step process |
| `about.html` | Owner story, why-soft-wash, equipment, licensing, eco notes |
| `contact.html` | Quote request form (stubbed submit) + direct contact info |
| `card/` | Business card (interactive flip + print sheet) |
| `dist/gerardo-card.pdf` | Print-ready PDF for Vistaprint / any printer |

## Local preview

```bash

python3 -m http.server 8000
open http://localhost:8000
```

```bash

```

## Tech

- **No build step.** Pure static HTML / CSS / vanilla JS — drop the folder on any static host.
- **Bilingual** via `i18n.js` (EN/ES) — `data-i` attributes resolve from a single dictionary; preference persists in `localStorage`.
- **Tokens & fonts** are shared with the business card via `shared/tokens.css` + `shared/fonts.css` — change a color in one place and it cascades.
- **Hero + icons** are inline SVG (no external images required).
- **Map** is hand-drawn SVG (Duval, St. Johns, Clay, Nassau).
- **Quote form** is a stub — submit logs payload to console + shows success state. To wire it live, replace the `SUBMIT_STUB` block at the bottom of `contact.html` with a `fetch()` to your handler.
- **Card pipeline**: `scripts/build-qr.sh` regenerates QR codes; `scripts/build-print.sh` produces the print-ready PDF in `dist/` via Chrome headless.

| `(904) 555-0100` | every page + `scripts/build-qr.sh` | actual phone |
| `gerardo@gerardopressurewash.com` | every page | actual email |
| `gerardopressurewash.com` | every page + `scripts/build-qr.sh` | actual website (or remove) |
| `[year]` | `about.html`, `i18n.js` | the year Gerardo started |
| Testimonial quotes | `index.html` + `i18n.js` | real customer quotes |

After updating phone / website, rebuild the QR codes and PDF:

```bash
./scripts/build-qr.sh
./scripts/build-print.sh
```

## Branding

Same visual system as the SDC Solutions site (navy ink, Outfit + Inter typography), with a **water-blue accent** (`#0EA5E9`) instead of green to differentiate the brand. Logo is a custom SVG wordmark with a spray-nozzle icon — no shared marks with SDC.
